# Power Electronics Symbols

**个人主页：** [https://hangdah.github.io/](https://hangdah.github.io/)

**项目地址：** [https://github.com/hangdah/Power-Electronics-Symbols](https://github.com/hangdah/Power-Electronics-Symbols)

电力电子 SVG 符号库，用于电路原理图、论文插图和演示文稿。当前收录 **22 个符号**，包含 MOSFET、二极管、电容、电阻、电感、变压器及交直流源等，并提供 Illustrator 源文件。

**[下载全部 SVG](Power_Electronics_Symbols_SVG.zip?raw=true)** · **[浏览 SVG 文件](SVG/)** · **[下载 Illustrator 源文件](Illustrator/Power_Electronics_Symbols.ai?raw=true)**

## 下载与使用

- **全部下载**：点击上方“下载全部 SVG”，获取包含全部符号的 ZIP 压缩包。
- **单个下载**：进入 [SVG 文件夹](SVG/)，打开需要的文件，使用 GitHub 文件页面的下载入口保存。
- **使用符号**：将 SVG 导入支持该格式的绘图、文档或演示软件，可按需要缩放。
- **编辑源文件**：使用 Adobe Illustrator 打开 [AI 源文件](Illustrator/Power_Electronics_Symbols.ai)。

下载整个仓库后，也可以双击 `index.html` 浏览全部符号。页面中，每个符号下方的 **Download** 按钮用于单独下载，顶部的 **Download All (ZIP)** 按钮用于打包下载，无需安装依赖或进行额外操作。
